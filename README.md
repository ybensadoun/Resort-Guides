# Resort Guides

A phone guest guide for resorts: one site with many villas or rooms, and different guests at once. Each guest sees their own villa, what the resort shares (pools, restaurant, front desk), and what is around it. It works offline and opens from a link or a QR code.

It starts in the Philippines, in English and Korean, and is built on a copy of the [Guest Guides](https://github.com/ybensadoun/guest-guides) engine so it can merge back into it.

- Plan and decisions: [docs/plan.md](docs/plan.md)
