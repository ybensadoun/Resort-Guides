# Sites

One folder per resort guide, in the same shape as a Guest Guides site (`site.json`, `content/`, `i18n/`, `public/`, `theme.css`), plus `site.type`, `site.country` and `content/units.json` (see `../docs/plan.md`).

Only made-up demo resorts (`demo-*`) are in git. A real resort's folder stays on this computer and is ignored by `.gitignore`: this repo is public.
